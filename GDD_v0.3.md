## 1. Концепция

Water Measure — мобильная игра-головоломка про переливание воды. Представляет собой визуальную интерактивную модель классических математических задач на переливание жидкости.

Игрок управляет несколькими сосудами разного объёма и путём переливаний должен отмерить заданный объём в одном из сосудов.

### 1.1. Типы задач
- **С источником** — один из сосудов является «источником» (визуально — раковина/кран), технически это обычный сосуд с очень большим объёмом. Из него можно наливать и в него можно выливать воду.
- **Без источника** — все сосуды изолированы, вода только переливается между ними.

### 1.2. Платформа
Android, мобильное устройство. Ориентация — **портрет**.

---

## 2. Основной игровой цикл (Core Loop)

1. Игрок видит уровень: сосуды с водой + цель.
2. Тап по сосуду-источнику → сосуд подсвечивается (выбран).
3. Тап по сосуду-приёмнику → вода переливается.
4. Проверка условия победы:
   - **Победа** → попап «Уровень пройден», +50 монет (за первое прохождение), переход к следующему.
   - **Нет** → игрок продолжает переливать (шаг 2).

Цикл повторяется до победы.

---

## 3. Правила

### 3.1. Механика переливания

**Выбор источника:**
- Тап по непустому сосуду выбирает его как источник.
- Выбранный сосуд подсвечивается.
- **Пустой сосуд нельзя выбрать как источник** (выделение не срабатывает).

**Выбор приёмника:**
- Тап по другому сосуду → перелив воды.
- Формула перелива: `amount = min(source.currentVolume, target.capacity − target.currentVolume)`.

**Повторный тап по выбранному сосуду:**
- Снимает выделение. Игрок может перевыбрать сосуд.

**Перевыбор (если выбранный приёмник полный):**
- Если игрок выбрал источник, а затем тапнул по полному сосуду (куда нельзя перелить), выделение с источника снимается, а этот полный сосуд становится новым источником. Таким образом игрок может быстро перевыбрать.

**Запреты:**
- ❌ Перелив в самого себя.
- ❌ Перелив из пустого сосуда.
- ❌ Перелив в полный сосуд.

**Источник (раковина/кран):**
- Технически это обычный сосуд с `capacity = v1 + v2 + targetVolume + 1` и `initialVolume = capacity`.
- Флаг `isSource = true` используется только для исключения из проверки победы.
- Визуально может выглядеть как раковина или кран.

### 3.2. Условие победы

Победа наступает, когда в **любом сосуде, кроме источника** (`isSource == false`), оказывается **целевой объём** воды: `vessel.currentVolume == targetVolume`.

Проверка происходит после каждого перелива.

### 3.3. Обучение (туториал)

Уровни 1–3 — обучающие:
- Пошаговые подсказки через всплывающие панели с затемнением экрана и стрелками.
- Шаг 1: показать, как выбрать сосуд.
- Шаг 2: показать, как перелить воду.
- Шаг 3: показать, как достичь цели.
- После первого успешного перелива обучение продолжается до уровня 3 включительно.

## 4. Компоненты уровня

Каждый уровень содержит:

- **3 сосуда** (2 обычных + 1 источник, либо 3 обычных) с параметрами:
  - `capacity` — максимальный объём.
  - `initialVolume` — начальное количество воды.
  - `currentVolume` — текущее количество (меняется в процессе игры).
  - `isSource` — флаг источника.
- **Целевой объём** (`targetVolume`) — число, которое нужно получить.
- **Пошаговое решение** (`solution`) — массив состояний для подсказок (опционально).

---

## 5. Управление

### 5.1. Основные действия

| Действие | Что происходит |
|---|---|
| Тап по непустому сосуду | Выбор сосуда (подсветка) |
| Тап по другому сосуду | Перелив воды из выбранного в этот |
| Повторный тап по выбранному | Снятие выделения |
| Кнопка «Подсказка» | Показывает следующее правильное действие (стоит 20 монет) |
| Кнопка «Сброс» | Возвращает сосуды в начальное состояние (списывает жизнь, если уровень активный) |
| Кнопка «Меню» | Открывает паузу |
| Кнопка «Отмена хода» (Undo) | Платная механика: 10 монет |

### 5.2. Меню (пауза)

- Продолжить
- Настройки
- Рестарт уровня (списывает жизнь, если уровень активный)
- Главное меню

### 5.3. Настройки

- Звуки (вкл/выкл)
- Музыка (вкл/выкл)
- Язык (RU / EN)

Настройки сохраняются в DataStore.

## 6. Прогрессия

### 6.1. Уровни

- Всего **20 уровней** (в первом релизе).
- Уровни 1–3 — обучающие.
- Прогрессия сложности: простые → средние → сложные.

### 6.2. Разблокировка

- Уровень N+1 открывается после прохождения уровня N.
- Открытые уровни хранятся в DataStore.

### 6.3. Сохранение прогресса

Через DataStore:
- `SelectedLevel` — последний выбранный уровень.
- `UnlockedLevels` — количество открытых уровней.
- `SavedCoins` — баланс монет.
- `SoundEnabled`, `MusicEnabled` — настройки звука.
- `Language` — выбранный язык (ru/en).
- `Lives` — текущее количество жизней.
- `NextLifeTime` — время до восстановления следующей жизни.
- `CurrentLevelState` — текущее состояние сосудов на уровне.

**Важно:** при выходе из игры состояние уровня сохраняется. Жизни при выходе не списываются.

## 7. Экономика и жизни

### 7.1. Монеты

| Действие | Монеты |
|---|---|
| Стартовый баланс | 100 |
| Первое прохождение уровня | +50 |
| Повторное прохождение уровня | +10 |
| Использование подсказки | −20 |
| Отмена хода (Undo) | −10 |

Монеты хранятся в DataStore и отображаются в верхней панели игрового экрана.

### 7.2. Жизни

- Максимум **5 жизней**.
- Восстановление **1 жизни за 10 минут** (реального времени, работает даже при закрытом приложении).
- Списание жизни:
  - При **поражении** на **активном** (непройденном) уровне (исчерпан `stepLimit` или `timeLimit`).
  - При **ручном рестарте активного** (непройденного) уровня.
- Жизнь **не списывается**:
  - При выходе из игры (состояние сохраняется).
  - При рестарте **пройденного** уровня (перепрохождение бесплатно).
  - При Undo.
  - При прохождении уровня.
- При 0 жизнях игрок не может начать новый уровень или продолжить текущий до восстановления.
- **Монетизация (не в первом релизе):** покупка жизней за донат-валюту или за рекламу. В v0.3 не реализуется, только заложено место в UI.

## 8. UI / UX

### 8.1. Экраны

1. **MainMenu** — главное меню (Play, Settings, Exit).
2. **LevelSelect** — выбор уровня (сетка кнопок, заблокированные/открытые).
3. **Game** — игровой экран.

### 8.2. Игровой экран

- **Верхняя панель:** номер уровня, таймер (MM:SS), монеты, жизни (5 сердечек).
- **Центр:** сосуды с водой.
- **Низ:** кнопки «Подсказка», «Сброс», «Меню», «Отмена хода» (если доступна).

### 8.3. Попап завершения уровня

Содержит:
- Текст «Уровень N пройден!»
- Время прохождения
- Награда: +50 монет (первое прохождение) / +10 (повторное)
- Кнопка «Продолжить» → переход к следующему уровню

На последнем уровне (20) кнопка «Продолжить» заменяется на «Конец игры» → возврат в `LevelSelect`.

### 8.4. Визуальный стиль

Используются стандартные возможности Android Studio (XML-разметка, Canvas для сосудов). Спрайты из Unity не переносятся. Стиль — минималистичный, геометрические фигуры.

## 9. Визуальные эффекты и звук

Игра — математическая головоломка, поэтому визуал минималистичный.

### 9.1. Вода
- Вода отрисовывается как **голубой прямоугольник** внутри сосуда.
- При переливании **высота прямоугольника плавно изменяется** (анимация ~300 мс).
- **Пузырьки**: опционально можно добавить лёгкую анимацию пузырьков внутри воды (зацикленные круги, поднимающиеся вверх). Не обязательно для первого прототипа, но можно сделать позже.
- **Цвета не смешиваются**, никаких «брызг» и «партиклов» нет.

### 9.2. Звук
- Звук переливания: mp3-файл (предоставляется отдельно), воспроизводится при каждом успешном переливе.
- Звук победы: короткий звуковой сигнал.
- Звук клика: лёгкий щелчок при выборе сосуда.
- Музыка: отдельный трек для главного меню и для игрового процесса.
- Управление звуком через настройки, состояние сохраняется в DataStore.

## 10. Локализация

- Поддерживаемые языки: **русский (ru)** и **английский (en)**.
- При первом запуске язык определяется по настройкам устройства.
- Игрок может сменить язык в настройках.
- Все тексты вынесены в `strings.xml` (values/strings.xml — английский, values-ru/strings.xml — русский).
