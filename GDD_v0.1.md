## 1. Концепция

**Water Measure** — мобильная игра-головоломка, которая представляет собой визуальную интерактивную модель классических математических задач на переливание жидкости. 

Игроку даются сосуды разного объёма (чаще всего 3). Некоторые из них могут быть пустыми, некоторые — полными. Цель — путём переливания воды отмерить точный целевой объём в одном из сосудов.

### 1.1. Типы задач
1. **Без источника (классические):** сосуды изолированы, общее количество воды фиксировано.
2. **С источником (кран):** один из объектов работает как кран. Из него можно набирать воду, и в него можно выливать лишнюю.

### 1.2. Платформа
Android, мобильные устройства. Ориентация — портретная (вертикальная). Язык разработки — Java (Android Studio).

---

## 2. Основной игровой цикл (Core Loop)

1. Игрок видит уровень: сосуды с водой (источник, если есть) и целевой объём.
2. **Тап по сосуду-источнику** → сосуд подсвечивается (выбран).
3. **Тап по сосуду-приёмнику** → вода переливается по математическим правилам.
4. Проверка условия победы:
   - **Победа** → попап «Уровень пройден», начисление наград, переход к следующему.
   - **Нет** → игрок продолжает делать переливы (возврат к шагу 2).

Цикл повторяется до победы или сброса уровня.

---

## 3. Правила (для игрока)

### 3.1. Механика переливания
- **Выбор:** Игрок тапает по сосуду, из которого хочет вылить воду. Сосуд подсвечивается.
- **Действие:** Игрок тапает по другому сосуду, чтобы перелить туда воду.
- **Запреты:** Нельзя переливать в самого себя, из пустого сосуда или в полный сосуд. Если действие невозможно, ничего не происходит.

### 3.2. Условие победы
Победа засчитывается, когда в **любом** сосуде (кроме крана-источника) оказывается **целевой объём** воды, указанный в задании.

---

## 4. Управление и интерфейс (UI)

### 4.1. Игровые действия

| Действие | Что происходит |
|---|---|
| Тап по сосуду | Выбор сосуда (подсветка) |
| Тап по другому сосуду | Перелив воды из выбранного в этот |
| Кнопка «Подсказка» | Показывает следующее правильное действие (стоит монеты) |
| Кнопка «Сброс» (Restart) | Возвращает сосуды в начальное состояние |
| Кнопка «Меню» | Открывает паузу |

### 4.2. Экраны игры
1. **Главное меню:** Кнопки «Играть», «Настройки», «Выход».
2. **Выбор уровня:** Сетка 5×4 для 20 уровней (заблокированные/открытые).
3. **Игровой экран:**
   - Верхняя панель: номер уровня, таймер (если есть лимит), монеты.
   - Центр: сосуды с водой и визуальная подсказка целевого объёма.
   - Низ: кнопки «Подсказка», «Сброс», «Меню».

## 5. Обучение (Туториал)

Уровни 1–3 — обучающие. 
Обучение реализуется через **затемнение экрана** с отображением белого текста и стрелок-указателей. 
- Шаг 1: указатель показывает, куда нажать, чтобы выбрать сосуд.
- Шаг 2: указатель показывает, куда нажать, чтобы перелить воду.
После первого успешного перелива затемнение исчезает, и игрок продолжает решать уровень самостоятельно.

## 6. Прогрессия и экономика

### 6.1. Уровни
- Всего **20 уровней** в стартовой версии.
- Прогрессия сложности: простые → средние → сложные.
- *Таблица 20 уровней находится в разработке (будет создана в Google Sheets, оттуда перенесена в игру в формате JSON/базы данных).*

### 6.2. Разблокировка и сохранения
- Уровень N+1 открывается после прохождения уровня N.
- Прогресс, открытые уровни и монеты сохраняются в памяти устройства (БД Room / DataStore).

### 6.3. Экономика (монеты)
- Стартовый баланс: 100 монет.
- Прохождение уровня: +100 монет.
- Использование подсказки: −20 монет.

## 7. Визуальный стиль, звук и локализация

### 7.1. Визуальный стиль
- **Стиль:** 2D-графика. Ориентир — комнаты с раковинами и бутылочками (как в старом прототипе на Unity). 
- **Источник (кран):** В идеале — спрайт раковины, из которой можно набирать и сливать воду. Если реализация в Android Studio будет слишком сложной, допустим упрощённый вариант (например, большая бочка с краном или значком бесконечности).
- **Примечание:** Точный визуал (спрайты или отрисовка кодом через Canvas) будет утверждён на этапе прототипирования (Спринт 2).

### 7.2. Звук
- **Звуки:** Перелив воды, клик кнопок, звук победы.
- **Музыка:** Фоновый трек (вкл/выкл в настройках).

### 7.3. Локализация
- Игра должна поддерживать **русский (RU)** и **английский (EN)** языки. 
- Реализация через стандартные ресурсы Android Studio (`strings.xml`), чтобы в будущем можно было легко добавить другие языки.
