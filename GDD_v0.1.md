## 1. Концепция

Math Water — мобильная игра-головоломка про переливание воды.
Представляет собой **визуальную интерактивную модель классических математических
задач на переливание жидкости**.

Игрок управляет несколькими сосудами разного объёма и путём переливаний должен
отмерить заданный объём в целевом сосуде.

### 1.1. Типы задач
- **С бесконечным источником** — один из сосудов может наполняться бесконечно.
- **Без бесконечного источника** — сосуды изолированы, вода только переливается
  между ними.

## 2. Основной игровой цикл (Core Loop)

1. Игрок видит уровень: сосуды с водой + цель.
2. Тап по сосуду-источнику → сосуд подсвечивается (выбран).
3. Тап по сосуду-приёмнику → вода переливается.
4. Проверка условия победы:
   - **Победа** → попап «Уровень пройден», +100 монет, переход к следующему.
   - **Нет** → игрок продолжает переливать (шаг 2).

Цикл повторяется до победы.

## 3. Правила

### 3.1. Механика переливания

**Выбор источника:**
- Тап по сосуду выбирает его как источник.
- Выбранный сосуд подсвечивается.

**Выбор приёмника:**
- Тап по другому сосуду → перелив воды.
- Формула перелива:  
  `amount = min(source.currentVolume, target.capacity − target.currentVolume)`
  (переливается столько, сколько влезает в приёмник, но не больше, чем есть в источнике).

**Запреты:**
- ❌ Перелив в самого себя.
- ❌ Перелив из пустого сосуда (нечего лить).
- ❌ Перелив в полный сосуд (нет места).

**Особый объект — «Sink» (слив):**  
в коде присутствует сущность `Sink`, которая может служить источником или приёмником
в зависимости от уровня. [TODO уточнить, как именно работает слив для игрока и
в каких уровнях используется.]

### 3.2. Условие победы

Победа наступает, когда в **целевом сосуде** оказывается **целевой объём** воды:
`targetVessel.currentVolume == targetVolume`

Проверка происходит после каждого перелива.

### 3.3. Обучение (туториал)

Уровни 1–2 — обучающие:
- Пошаговые подсказки через всплывающие панели (`Backgr1`, `Backgr2`).
- Шаг 1: показать, как выбрать сосуд.
- Шаг 2: показать, как перелить воду.
- После первого успешного перелива обучение заканчивается, включается
  обычный игровой интерфейс (`PanelLevel`).

## 4. Компоненты уровня

Каждый уровень содержит:

- **N сосудов** с параметрами:
  - `capacity` — максимальный объём.
  - `initialVolume` — начальное количество воды.
  - `currentVolume` — текущее количество (меняется в процессе игры).
- **Целевой сосуд** (`targetVessel`) — в нём нужно получить целевой объём.
- **Целевой объём** (`targetVolume`) — число, которое нужно получить.
- **Минимальное количество шагов** решения — используется подсказками.

## 5. Управление

### 5.1. Основные действия

| Действие | Что происходит |
|---|---|
| Тап по сосуду | Выбор сосуда (подсветка) |
| Тап по другому сосуду | Перелив воды из выбранного в этот |
| Кнопка «Подсказка» | Показывает следующее правильное действие (стоит 20 монет) |
| Кнопка «Сброс» | Возвращает сосуды в начальное состояние (бесплатно) |
| Кнопка «Меню» | Открывает паузу |

## 6. Прогрессия

### 6.1. Уровни

- Всего **20 уровней**.
- Уровни 1–2 — обучающие.
- Прогрессия сложности: простые → средние → сложные.
- **Таблица 20 уровней** — TODO (в процессе, будет в v0.2).

### 6.2. Разблокировка

- Уровень N+1 открывается после прохождения уровня N.
- Открытые уровни хранятся в `PlayerPrefs` (ключ `UnlockedLevels`).

### 6.3. Сохранение прогресса

Через `PlayerPrefs`:
- `SelectedLevel` — последний выбранный уровень.
- `UnlockedLevels` — количество открытых уровней.
- `SavedCoins` — баланс монет.
- `SoundEnabled`, `MusicEnabled` — настройки звука.
